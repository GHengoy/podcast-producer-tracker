Edit ran long. The buffer day saved us.

Friday

  • Five phases. Recording, editing, show notes, publishing, and promotion each get a deadline.
  • Work backwards. Editing usually takes 3-7 days; show notes land 1-2 days before publish.
  • Build in buffer. If an edit takes 3 days, plan 4 so delays don't cascade.
